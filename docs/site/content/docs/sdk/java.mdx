<Callout type="warn">
  **Planned — not currently published.** The repository currently publishes the JavaScript / TypeScript SDK only.
</Callout>

There is no official Java artifact or supported Maven/Gradle dependency at this time. Do not use a guessed Maven coordinate.

When a Java SDK is released, this page will cover:

- Supported JDK versions and Maven/Gradle installation.
- TCP connection and authentication.
- Queue and exchange declarations.
- Publishing and consuming messages.
- ACK/NACK and delivery settlement.
- Connection recovery and exception handling.
- Protocol-version compatibility.

A Java client implemented independently against the wire format is not currently an officially supported SDK.
