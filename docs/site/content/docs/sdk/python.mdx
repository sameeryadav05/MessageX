<Callout type="warn">
  **Planned — not currently published.** The repository currently publishes the JavaScript / TypeScript SDK only.
</Callout>

There is no official Python package or supported Python installation command at this time. Do not use a guessed package name from PyPI.

When a Python SDK is released, this page will cover:

- Supported Python versions and package installation.
- Connection and authentication.
- Queue and exchange declarations.
- Publishing JSON messages.
- Consuming messages and ACK/NACK.
- Reconnection and error-handling behavior.
- Compatibility with the MessageX protocol version.

Until then, Python applications would need a separately implemented TCP protocol client. Such a client is not an officially supported SDK.
